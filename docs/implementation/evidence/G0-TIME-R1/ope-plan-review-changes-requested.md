### P2 — Name the external-Q, provenance and variance boundaries concretely

OBP's mathematical API is relevant even though its runtime is not presently a suitable default. Exact release source `obp-0.5.7/obp/ope/estimators.py` provides public `DoublyRobust(lambda_=np.inf, use_estimated_pscore=False).estimate_policy_value(reward, action, action_dist, estimated_rewards_by_reg_model, pscore, position=None)`. Action/Q arrays have shape `(n,2,1)` for this application. Lines 977–994 integrate over action probabilities and add the logged-action residual correction; lines 998–1075 validate inputs and return the mean without fitting. Per-record output is an underscored method, not a stable public API. The stock interval path resamples row scores. `RegressionModel.fit_predict` uses ordinary shuffled KFold, not patient/forward-time splits. Source locators: estimators.py 857–1175, regression_model.py 214–325, utils.py 45–86 and 313 onward in the hashed sdist.

Any future OBP reference must call that public value API with externally generated Q. Its default training examples and interval API cannot qualify REMission's split/uncertainty requirements. For an independent per-record reference, call the public scalar API on singleton batches; do not silently depend on `_estimate_round_rewards`. Project validation must additionally check finite values, action identity, availability, actual logging propensity, target normalization, data lineage and temporal/patient exclusions. Passing arrays to a library does not authenticate their held-out provenance.

The plan's acceptance list preserves these requirements in principle but does not yet select the estimand's aggregation denominator or uncertainty regime. Before implementation, declare whether the fixed-policy target averages eligible decision points or patient-level summaries; unequal patient record counts distinguish these. Patient resampling must retain all records and declared weights for each sampled patient, preserve paired comparisons, and use the declared fixed-nuisance or nuisance-refitting protocol. Neither row bootstrap nor patient bootstrap inside one pooled adaptive cohort establishes uncertainty for the learning algorithm. Independent complete-cohort runs remain the latter's unit.

## Observable qualification criteria and retained provenance

- Use independent rational/hand calculations for nonuniform logging, nondegenerate stochastic targets and nonzero Q; compare each score and the declared aggregate within a prespecified float64 tolerance. Include Q=0 reducing DR to ordinary IPS, zero factual residual, target probability zero for a logged action, and deterministic permitted targets. A fixture where both Q entries differ detects replacing integration with the chosen-action Q.
- Test supported eligible sets explicitly. A one-action available set with compatible deterministic target/logging can be represented if the estimand includes it; a two-action randomized-contrast analysis must exclude it by declared design. Reject target mass on unavailable or unsupported actions, logged unavailable actions, zero/out-of-range/nonfinite logging probability, invalid action identity/order, non-normalized target, malformed/nonfinite Q/rewards, and missing reward without an accepted observation strategy. Never replace a bad probability with one or silently renormalize an infeasible target.
- Record the fixed target hash/version before evaluation. Make target training, reward fitting and sampled prediction unavailable in the score evaluator; assert zero such calls and invariance of target/Q artifacts. Changing evaluation rewards must change residual scores but cannot change Q, policy or training provenance.
- Produce Q from actual outside-evaluation patient/cohort data and forward-time allowed histories. Preserve training/evaluation ID manifests, fold IDs, fit/prediction times, observation available-at cutoffs, feature and model versions, seeds and raw-byte hashes. Mutations that add an evaluation patient, future-available reward/feature, mismatched row/action ordering or altered Q file must fail before estimator work. Initial folds lacking legitimate earlier training data require prespecified training-only warm-up or abstention, never future fitting.
- For clustered fixed-policy inference, use unequal-length patient fixtures and repeated correlated records to distinguish patient resampling/contributions from row resampling. Independently verify aggregation and variance/interval calculations, pairing and seed reproducibility. Explicitly reject insufficient independent units. State whether nuisance refits occur during bootstrap and what inferential target is claimed. For pooled adaptive learning, preserve complete-cohort replication and paired cohort uncertainty separately.
