### Current review knowledge, store publication and all active obligations

`reviews` records a **current authenticated assessment performed through this service**, not an external retrospective assessment. Its strict request has no assessed_at/recorded_at/available_at. Supplying any such field rejects422. After acquiring gate, checking common generation/session/owner and reading the exact committed evidence closure and active episode, sample server `current_review_at=C`; then require C >= generation.opened_at, C >= every effective trigger operation receipt/changed-obligation receipt being reviewed and C >= last committed patient operation time. Equality is valid with the known operation order. Request binds exact current decision/four versions/generation/trigger-set digest; missing or old facts reject. The service saves assessed_at=C, recorded_at=C and nominal availability=C with actual committed-operation identity; no historical assessment claim is inferred. Clearance has its own later service receipt R>=C and never backdates effective clearance.

For each referenced item, record a `CommittedEvidenceAccess` proof in the review: store/namespace/partition/record/hash, source event/recorded/available clocks, committed object/receipt identity, `verified_visible_at=C` and the current service authority generation. The proof comes from a committed DB read while holding gate **before inserting the review**; no caller assertion or same-transaction newly inserted evidence qualifies. Exact reference heads are revalidated again at clearance. Actual access at C is a conservative service knowledge bound, not a claim that C was the first physical publication time. Never substitute source declared availability or a precommit receipt timestamp for this committed access proof.

| Evidence store | Required publication/knowledge check at current review |
|---|---|
| `archive` | Stored archive row, original bytes, entry and full verified manifest/receipt must all be visible in the committed snapshot; exact configured package grant/owner/partition resolves. Its archived source times must be <=C. Archive received_at may have been sampled before commit; it is provenance, **not proof of earlier service accessibility**. Persist the archive receipt/hash plus current committed-read proof at C. An archive imported after an alleged earlier external assessment cannot justify backdating this current review. |
| `event` | Existing committed event row/raw/hash and live ingestion/projection receipt where present. Source event/recorded/effective available_at must be <=C; actual committed visibility is established by current read. For historical fixture/replay rows with no live_received_at, only present committed visibility is proved; do not invent earlier live publication. Lineage head chosen at current review must equal exact reference. |
| `live_review` | Earlier committed review and its operation receipt, same patient and authorized episode/requirement scope. Original current_review_at/recorded/available <=C and predecessor operation sequence < current review sequence. A review cannot reference itself or satisfy its own unrecorded assessment; source-only archive reviews cannot impersonate this store. |

Effective service knowledge bound for each item is max(source availability, proven service access time C), hence <=C only after the committed read succeeds. This deliberately makes no unsupported retrospective availability assertion. No clinical maximum-age/freshness interval is introduced: currentness means current generation/facts/authority plus a present authenticated attestation. Source facts can be old; the service assessment of them is now. If later work needs externally performed retrospective assessment, it requires a separately versioned provenance/knowledge contract and remains evidence distinct from this current attestation. It is not admitted as a caller-chosen assessment time in this package.

The review must cover the **union of all unresolved obligations of every active trigger in the episode**, not only the selected concern. Required evidence kinds/rules are explicit registry entries; the request must provide one result for every exact obligation ID/definition, without duplicates, omission or weaker substitute. Evidence publication and current generation alone cannot make a criterion clinically sufficient. Any active threshold obligation with no accepted rule blocks clearance of the whole mixed-reason episode even if all concern items are satisfied. Pending review may still be recorded for supported items, with unsupported obligations explicitly pending; it cannot create a satisfied whole-episode review. Other episodes are never implicitly covered.

Add exact acceptance counterexample: source fact declares08:00, archive first commits10:00, episode opens10:01. At10:02 `assessed_at=09:00` rejects as unknown field; the valid current request records C=10:02 and proof that archive was committed and read then. A source item whose declared availability is10:03 rejects at10:02 even if bytes are present. Uncommitted archive/event rows, same-transaction inserts, cross-patient receipts and stale hashes reject. Frozen equal-time case uses prior committed sequence as proof, not timestamp comparison alone. A later correction/publication cannot enter an earlier saved review, and clearance after any such material change requires a fresh current review. These extend LH17/LH19/LH21–23 without inventing scientific clearance policy.
