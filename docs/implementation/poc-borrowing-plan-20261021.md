## Marginal bridge and identification

Let theta contain the existing population means/SDs, sinusoid, rho, process/ISI SDs and adherence probability. Under the **declared modeling assumption**, a new source participant has independent `b~N(mu_b,sd_b²)`, `beta_j~N(population_beta_j,sd_beta_j²)` and daily taken indicators iid Bernoulli(p_adherence). These are distributions integrated using sampled hyperparameters, not the current patient's realized `b`, `patient_beta`, error or baseline observation. Reference source/target population hyperparameters, adherence law and measurement/process laws are shared. No new fitted source modifiers. Source baseline days-13..0 have no treatment, e starts zero at-14, and day42 outcome averages nights29..42. Absolute sinusoid phase matches the declared baseline origin.

The synthetic producer's uniform baseline/shared response is not the learner's normal independent hierarchy. “Compatible” means the source and local generator populations/laws match each other; it does not make the fitted model correctly specified. Keep this misspecification visible in PA6. Do not import the true uniform law, `.85`, coefficients or response draws into the learner to force agreement.

An aggregate randomized contrast identifies its source ITT mean under this design. Two same-population summaries provide more precision on that one contrast, not separate identification of baseline distribution, both treatment effects, heterogeneity, adherence, individual response or transport. Priors and local observations distinguish those components; borrowing changes them only through g(theta). Transport to this patient's H*-conditional target requires the shared-law/exchangeability/model assumptions; randomization of the source does not establish those assumptions. Bias/tau and robust mixture limit influence but do not repair nonidentification. With no local data, source conflict with the target is unknowable. Keep superiority disabled.

For arm j with decay r and input c (`.65/.35` or `.8/.2`), form fixed adherence weights for k=1..42:

`w_jk = (c/14) * sum_{t=max(29,k)}^42 r^(t-k)` (zero if lower bound exceeds42).

At quadrature nodes b,beta_j, recall mean and variance after integrating future processes are

`m_j = b + a*mean_{t=29..42} sin(2*pi*t/21) - beta_j*p*sum_k w_jk`

`v_j = beta_j²*p*(1-p)*sum_k w_jk² + sigma_e²*sum_{k=-13..42} h_k(rho)² + sigma_isi²`,

where `h_k = (1/14)*sum_{t=max(29,k)}^42 rho^(t-k)`. Compute powers by recurrence, including rho0/negative values, preserving finite gradients. AR variance includes baseline innovations; neither stationary variance nor the current patient's terminal error is substituted. Conditional on b/beta, only weighted Bernoulli adherence is Gaussian-approximated; AR and endpoint noise integration is exact. For normal latent endpoint X, `E[round_clip(X,0,28)] = sum_{q=1..28} P(X >= q-.5)`; use stable normal tails and explicit zero-variance limits in independent fixtures.

Apply fixed Gauss-Hermite weights to b and the active beta_j, separately per arm. There is no need for a tensor including the inactive arm: linearity of the marginal mean allows two two-dimensional integrals even with paired arm outcomes. g_s(theta)=E_E−E_C; identical declared populations/designs share one calculation across both study terms. Default order16 per axis, qualification order32, candidate promotions32/64 only after prefit qualification/version freeze. Store nodes, normalized weights and their hashes. No random draws, rounding of sampled parameters, or thresholded uniforms inside logp. Node count cannot adapt during NUTS. Analytically collapsing a normal dimension is a possible later optimization only after equivalence checks; it is not required now.

Use the canonical normalized mixture exactly:

`L_s = .5*N(d_s | g_s(theta)+bias_s, SE_s²+tau²) + .5*N(d_s | 0, SE_s²+100)`;

`bias_s~N(0,.5²)`, common `tau~HalfNormal(1)`, sensitivity `HalfNormal(2)`. Implement logsumexp with full normal constants; do not sample a discrete component assignment. The weak term is constant in theta. Report posterior informative responsibility from the normalized two terms, never an “effective patient count.” Each source contributes once per cumulative refit, with the original prior. V0 adds neither likelihood nor bias/tau variables; do not use yesterday's posterior as today's prior. Neither summary+IPD nor joint likelihood+MAP nor two copies under different study names is permitted.
