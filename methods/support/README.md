# Offline S1 methods

`data.build_features` consumes `PublicHistory(patient_id, origin, cutoff, records)` views of the existing typed public reduced records. A caller can construct one from a validated support `ProtocolHistory` without copying audit/source hashes or private generator state. The adapter checks the actual reduced record types, available-at clocks, unique nightly decisions, exact reduced references, final .5/.5 distribution, approved randomized assignment, outcome linkage and recorded quality. It does not add a wire contract, event store, cohort producer or executable request configuration.

For night `t=1..84`, the decision is at `origin+(t-1) days`; the five controls are `[1, latest quality available strictly before decision (7 if absent), no-prior-available-quality indicator, delivered public support prompts in the previous six nights, t/84]`. A more recent missing report preserves an older available quality. `n_t` counts public `delivery` records with `stage='delivered'`, never adherence or private habituation. Feature source references must have been persisted in the decision context. Active-only records cannot reconstruct an earlier report hidden by a later correction; that unsupported case rejects explicitly.

`wcls.fit(features, provenance_seed='fit/wcls-unused-provenance/<key>')` fits observed rewards only, with fixed `q=.5`, weights `q(A)/p(A)`, and sixth design column `A-.5`. It requires statsmodels 0.15.0; the actual NumPy/SciPy/Python versions are recorded. Statsmodels WLS uses the participant cluster sandwich with `use_correction=True`, `df_correction=True`, `use_t=True`; the interval uses `t(.975,G-1)`. At least eight contributing participants, `N>6`, both actions, rank six under the declared float64 SVD rule, and positive finite treatment variance are required. Rank failure abstains without deleting columns or repairing the design. The result retains identity, counts, diagnostics, coefficients, covariance, estimate, standard error, interval and inference df. Invalid required source data raises typed `InvalidInput`; insufficient statistical support returns typed `WCLSResult(status='abstained')`.

The independent MCAR reporting probability is .1 in the restricted representative. Missing rewards never become zeros or imputed primary rows. This is the eligible S1 decision-point average proximal quality excursion, not an ordinary unrandomized physician-choice contrast. Twelve default participants do not guarantee rank, interval calibration or sufficient retained clusters. Ordinary cluster-t intervals do not establish adaptive-cohort inference or MNAR robustness.

The separate R1 sensitivity uses all completed eligible observed **and missing** S1 contexts with equal decision weights. For each of nine ordered `(delta0,delta1)` pairs in `{-0.5,0,+0.5}²`, it reports primary beta plus the average `.1*(d1-d0)`, where `m_a=clip(controls@gamma+(a-.5)*beta,0,10)` and `d_a=clip(m_a+delta_a,0,10)-m_a`. Zero/zero exactly recovers beta. The clipped conditional-mean working approximation is not protected by WCLS's marginal robustness. These are assumption-driven point estimates with descriptive directions/range; there is no sensitivity interval, sampling uncertainty estimate, MCSE, identified MNAR correction or inferential sign-reversal claim. Invalid required missing-only context withholds the sensitivity and labels its counts incomplete while retaining a valid primary. S2 is not an input or prerequisite.
